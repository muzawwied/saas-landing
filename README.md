# Vylonium — SaaS Landing Page

Production landing page for Vylonium, the all-in-one operating platform for modern SaaS.

Live: https://muzawwied.github.io/saas-landing/

## Highlights
- Light, professional theme — zero dependencies, no build step, no external requests
- Animations: preloader, typing effect, scroll reveal, animated counters, logo marquee, 3D tilt, scroll progress bar, testimonial carousel, accordion FAQ
- Production mode: SEO + Open Graph meta, sitemap.xml, robots.txt, custom 404, responsive (mobile-first breakpoints), prefers-reduced-motion support, svh units, overflow-safe layout
- Pure HTML/CSS/JS — every visual (dashboard mockups, charts) is drawn in CSS/SVG

## Structure
- `index.html` — the entire site (single page, all sections)
- `404.html`, `robots.txt`, `sitemap.xml` — production support files
